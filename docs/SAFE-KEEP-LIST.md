# الحزم والخدمات التي يجب الحفاظ عليها مبدئياً

هذه قائمة حماية مبدئية قبل فحص الجهاز. لا تعني أن كل هذه الحزم يجب أن تبقى مفتوحة دائماً؛ المقصود عدم تعطيلها أو حذفها قبل اختبار الوظائف واعتمادياتها.

## وظائف يجب أن تبقى متاحة

| الوظيفة | ما يجب الحفاظ عليه |
|---|---|
| أساس Android | System Server ومكونات الإقلاع وSystemUI وSettings وPackage Installer وDownload Provider وMedia Provider والتخزين ومكونات الشبكة |
| اللمس والشاشة | خدمات Input وTouch وDisplay والواجهة الحالية إلى أن يصبح Launcher الجديد افتراضياً ويجتاز الاختبار |
| الصوت | Audio/Flinger وخدمات الوسائط ومكونات Bluetooth Audio |
| الهاتف والشريحة | Telephony وRadio Interface Layer وPhone وTelephony Provider وSMS/MMS عند الحاجة |
| الاتصال | Wi-Fi وBluetooth وUSB وDHCP وNetwork Location |
| الملاحة والسرعة | GPS/Location Provider ومكونات الموقع، مع تطبيق خرائط متوافق |
| خدمات Google | لا نعطّل Google Play services وGoogle Services Framework وPlay Store قبل اختبار تطبيق الخرائط المثبت. لكن Android 5 خارج دعم إصدارات Google Play services الحالية؛ نحتفظ بالنسخة الموجودة مؤقتاً ونختبرها، ولا نفرض تحديثاً حديثاً عليها |
| الطاقة | Battery/Power Management وUSB/Charger وThermal ومراقبة الطاقة |
| النظام والملفات | Settings وPermissions وDownload Manager وStorage وMedia Scanner ومكونات الحسابات الضرورية |

## ما يمكن أن يدخل قائمة التعطيل بعد جرد الجهاز

- تطبيقات ASUS الترويجية أو السحابية أو الدعم التي لا تستخدمها، بعد التأكد من أنها ليست مرتبطة بتعريفات أو تحديثات النظام.
- تطبيقات تجريبية أو نسخ مكررة من مشغل الموسيقى/الفيديو/المتصفح، مع إبقاء التطبيق الذي نختاره فعلياً.
- خدمات النسخ الاحتياطي والمزامنة غير المستخدمة، بعد التأكد من أنها ليست مطلوبة لتسجيل الدخول أو Maps.
- أدوات اجتماعية أو بريد أو ألعاب أو عروض مثبتة من المصنع لا نحتاجها.
- Widgets وخلفيات حية وخدمات طقس/أخبار تعمل بالخلفية إذا لم نستخدمها.

## ما لا يجوز تعطيله بالتخمين

- أي حزمة باسم Android System أو SystemUI أو Settings أو Package Installer.
- أي حزمة مرتبطة باللمس أو الشاشة أو الصوت أو الاتصالات أو Bluetooth أو Wi-Fi أو GPS أو USB أو البطارية أو التخزين.
- Google Play services أو Google Services Framework أو Play Store قبل تجربة الملاحة الفعلية ومعرفة اعتماديات تطبيق الخرائط.
- تطبيق الهاتف أو جهات الاتصال أو Telephony Provider إذا كان الجهاز سيبقى هاتفاً أو سيستخدم اتصال البيانات بالشريحة.

## آلية التنفيذ

1. أخذ تقرير الحزم من الجهاز الفعلي، بما فيه أسماء الحزم ومسارات APK والحزم المعطلة.
2. تحديد التطبيقات المراد استخدامها فعلاً، ثم معرفة التطبيق الذي يفتح لكل وظيفة.
3. تجربة تعطيل حزمة واحدة فقط عبر `pm disable-user --user 0 PACKAGE`.
4. إعادة التشغيل وفحص الملاحة والصوت والمكالمات والبلوتوث والواي فاي وGPS والشحن.
5. عند أي خلل، استرجاعها فوراً عبر `pm enable --user 0 PACKAGE`.
6. لا نستخدم `pm uninstall` أو حذف ملفات من قسم system في مرحلة التخفيف الأولى.

## ملاحظات توافق الجهاز

- نسخة النظام التي تحققنا منها هي Android 5.0.2 / API 21، لذلك لا نختار تطبيقات حديثة لمجرد أنها متاحة على هواتف أحدث.
- مساعدة Google الحالية تقول إن Google Play services مدعومة حالياً على Android 7 فأحدث، وإن تحديثات Google Maps الحديثة تتطلب Android 9 فأحدث؛ لذلك قد تكون خدمات Google المثبتة على Android 5 نسخة قديمة غير قابلة للتحديث. وتذكر Google أن Maps Go متاحة على Android 4.4 فأحدث، وهي مرشح للتجربة بعد جرد الجهاز. يجب اختبار التطبيق الموجود فعلياً وعدم تنزيل APK حديث عشوائياً.
- مواصفات Z170CG المنشورة تذكر GPS وBluetooth وتشغيل الصوت، بينما لا تذكر موالف FM مدمجاً، ومصدر مواصفات الجهاز يدرج FM Radio على أنه غير متوفر. لذلك زر الراديو في الواجهة حالياً مخصص لراديو الإنترنت/تطبيق صوت؛ لا نعد براديو FM حقيقي من دون مستقبل خارجي.
