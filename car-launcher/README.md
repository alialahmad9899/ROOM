# Wesal Car Launcher — النسخة الأولية

تطبيق Launcher مستقل وخفيف لجهاز ASUS ZenPad C 7.0 P01Y.

## التوافق المقصود
- Android 5.0.2 / API 21 كحد أدنى.
- targetSdk 22 لتجنب فرض سلوك Android الحديث على نظام قديم.
- Java فقط، دون AppCompat أو مكتبات واجهات أو خدمات تحليل وإعلانات.
- APK نفسه لا يحتاج مكتبات native؛ لذلك يمكن تثبيته على نسخة Android x86 إذا اكتمل البناء والاختبار.

## الموجود حالياً
- شاشة عربية داكنة بأزرار كبيرة.
- اختصارات تفتح تطبيق الخرائط والموسيقى والهاتف والبلوتوث والإعدادات عبر intents القياسية.
- يظهر تنبيه واضح إذا لم يكن التطبيق المطلوب مثبتاً.
- يمكن اختياره كواجهة HOME افتراضية من إعدادات الجهاز.
- لا يعمل بخدمة دائمة ولا يجمع بيانات.

## غير مكتمل بعد
- اختبار فعلي على جهاز P01Y بدقة 1024×600.
- ضبط وضع أفقي وتوزيع البطاقات حسب مساحة الشاشة.
- إعداد شاشة التوصيل/الفصل والشاشة التلقائية؛ هذه المرحلة تحتاج صلاحيات واختباراً على الجهاز.
- لا يوجد حتى الآن تعطيل لحزم النظام.

## البناء
يتم البناء عبر GitHub Actions من workflow باسم Build car launcher. لا تعتبر نسخة Debug صالحة للتثبيت قبل نجاح البناء والاختبار على الجهاز.
