# Wesal Car Launcher — النسخة التجريبية 0.3.0

تطبيق Launcher مستقل وخفيف لجهاز ASUS ZenPad C 7.0 P01Y.

## التوافق المقصود
- Android 5.0.2 / API 21 كحد أدنى.
- targetSdk 22 لتوافق صلاحيات Android 5.
- Java فقط، دون AppCompat أو مكتبات واجهات أو تحليلات أو إعلانات.
- لا توجد خدمة دائمة؛ يتم تحديث عداد GPS فقط أثناء ظهور الواجهة.

## الواجهة الحالية
- لوحة أفقية عربية مصممة لشاشة 1024×600.
- عداد سرعة دائري يعرض السرعة بالكيلومتر/ساعة من GPS على تدريج حتى 200، ويعرض -- عند غياب الإشارة بدلاً من اختراع سرعة.
- أزرار كبيرة بتصميم بطاقات للملاحة والموسيقى وراديو الإنترنت والهاتف والبلوتوث والإعدادات. زر الراديو يفتح Acoustic (إذا كان مثبتاً)، ولا يخلط بين الراديو ومشغّل الموسيقى.
- اختصارات تفتح التطبيقات المثبتة عبر Android intents القياسية، وتعرض تنبيهاً إذا لم يوجد تطبيق مناسب.
- يمكن اختيار التطبيق كواجهة HOME افتراضية.
- لا تتضمن الواجهة راديو FM؛ مواصفات الجهاز لا تؤكد وجود موالف FM داخلي.

## قبل اعتماد عداد السرعة
القراءة GPS تقريبية وتتأثر بجودة الإشارة والتأخير. يجب مقارنتها بعداد السيارة واختبارها بمكان آمن؛ لا تستخدمها كبديل عن عداد السرعة المعتمد للقيادة.

## البناء
يتم البناء عبر GitHub Actions من workflow باسم Build car launcher. لا تعتبر نسخة Debug صالحة للتثبيت قبل نجاح البناء والاختبار على الجهاز الفعلي.

## تطبيق الراديو المقترح
- Acoustic: https://f-droid.org/packages/com.metalshard.projectwave/
- النسخة المنشورة في F-Droid تتطلب Android 5.0 أو أحدث، حجمها نحو 12 MiB، ولا تتضمن تتبعاً إضافياً حسب وصف المستودع.
- التطبيق غير مضمّن داخل APK الخاص بالواجهة؛ يثبت منفصلاً عند الحاجة فقط. يستخدم خدمة تشغيل أمامية أثناء الاستماع للراديو.
